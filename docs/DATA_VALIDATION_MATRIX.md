# Data Validation Matrix

Last updated: 2026-06-20

This matrix separates "official source exists" from "we have successfully used it in this app".

Statuses:

- `Docs verified`: official docs or catalogue found.
- `Access needed`: credentials, login, or approval required.
- `Smoke test pending`: ready to test with a small request.
- `Validated`: response/file downloaded and fields confirmed.
- `Blocked`: access, licence, or technical issue blocks use.
- `Rejected`: not suitable as a product data source.

## Validation Rules

1. A feature card cannot be marked as `real` unless the source has a `Validated` row.
2. If data is mocked, the UI should show it as sample or demo data.
3. If a provider is package-gated, the UI should show `Not connected` or `Access pending`.
4. AI-extracted fields must store source URL/document, extracted timestamp, confidence, and missing fields.
5. Area-level comparisons must show when different providers use different geography levels.

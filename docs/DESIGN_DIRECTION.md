# Design Direction

Last updated: 2026-06-20

The UI direction for AreaScope should feel calm, premium, and native-app inspired.

## Visual Principles

- Prefer iOS/macOS-style restraint: clean spacing, light surfaces, subtle depth, clear hierarchy.
- Keep screens quiet and useful. Avoid noisy cards, decorative gradients, dense badges, and overpacked dashboards.
- Use a premium research-tool feeling rather than a generic enterprise admin panel.
- Let maps, data tables, source panels, and opportunity comparisons carry the product. Decoration should stay minimal.
- Use rounded corners carefully: app panels can be soft, but cards and controls should remain disciplined.
- Typography should feel like a high-quality productivity app: strong headings, readable body text, compact labels.

## Practical UI Rules

- Use Panda CSS design tokens for color, spacing, radius, and shadow decisions.
- Use icons only where they clarify controls or data type.
- Keep source status labels visible but not visually loud.
- Keep maps as a mode/tab until the area workspace is useful.
- Do not build a marketing landing page as the first screen.
- Do not use large decorative blobs, heavy gradients, or random illustration cards.

## Product Feel

Target feel:

```txt
Apple-like research workspace
quiet property intelligence tool
premium but not flashy
structured but not corporate-heavy
```

Avoid:

```txt
generic SaaS dashboard
crypto-style gradients
crowded BI dashboard
real-estate marketing landing page
template admin panel
```
